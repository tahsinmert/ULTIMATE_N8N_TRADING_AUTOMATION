# Contributing to ULTIMATE_N8N_TRADING_AUTOMATION

Thank you for helping improve this project.

## Before you contribute

- Read the README end to end.
- Test changes in a safe environment before using live funds.
- Keep changes focused and easy to review.

## Contribution workflow

1. Open an issue if you want to discuss a change before coding.
2. Fork or branch from `main`.
3. Make one logical change per pull request.
4. Update documentation when behavior changes.
5. Describe the testing you performed.

## What good contributions look like

- Clear workflow improvements
- Safer trade validation logic
- Better documentation or examples
- Bug fixes with reproducible steps

## What to avoid

- Unclear or mixed-scope pull requests
- Silent behavior changes without documentation
- Live-trading changes without careful review

## Pull request checklist

- [ ] I tested the workflow or explained why testing was not possible.
- [ ] I updated the README or other docs if needed.
- [ ] I did not introduce secrets, credentials, or unsafe defaults.
- [ ] I described the impact of the change clearly.
