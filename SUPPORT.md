# Support

## Where to get help

- Open a GitHub issue for bugs or improvement requests.
- Use a pull request for proposed fixes.
- Review the README before asking setup questions.

## What to include

- The workflow version or commit hash
- The exact payload you used
- The node where the problem happened
- Any error message or screenshot

## What support can and cannot cover

- Documentation and workflow usage: yes
- Bug triage and reproducible issues: yes
- Live trading advice, profit guarantees, or financial guidance: no
