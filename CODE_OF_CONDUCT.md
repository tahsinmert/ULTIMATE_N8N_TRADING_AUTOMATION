# Code of Conduct

## Our pledge

We are committed to making this project a respectful, inclusive, and productive space for everyone.

## Expected behavior

- Be respectful and constructive.
- Focus feedback on ideas and implementation.
- Assume good intent while still being precise.
- Keep discussions relevant to the project.

## Unacceptable behavior

- Harassment, discrimination, or abusive language
- Personal attacks or intimidation
- Deliberate disruption of discussions or contributions
- Sharing private information without permission

## Enforcement

Project maintainers may remove or reject contributions that violate this code of conduct.

## Scope

This code of conduct applies to issues, pull requests, discussions, and any project-related interaction.
